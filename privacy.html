プライバシーポリシー / Privacy Policy

最終更新: 2026-11-08

対象

この道具（知識データベース / health-agent）は、作成者本人が自分の Google アカウントのデータだけを扱うために使います。他の人のアカウントからの利用は想定していません。

扱うデータ

  • Google Health API: 睡眠・心拍・活動・体の測定値・栄養など（読み取りのみ）
  • Google ドキュメント: 本人のドキュメント

使い方と保存

データは本人の手元の端末と本人の Google アカウントにだけ保存し、本人の健康管理と作業のためだけに使います。第三者への提供・販売・広告への利用はしません。Google API から得たデータの利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

削除

アクセスは Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。手元のデータは本人が削除します。

English summary

This tool is used only by its owner with the owner's own Google account. Data from Google APIs (Google Health API, Google Docs) is stored only on the owner's devices and Google account, used only for the owner's own health tracking and work, and never shared, sold, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account's third-party connections page.
